# Screen Specs

이 문서는 [V1 Scope](../product/v1-scope.md)의 목표 화면을 정의합니다.
현재 구현 파일과 일치하지 않을 수 있으며, 각 화면 구현 시 제품 정책·API 계약·테스트와 함께 갱신합니다.
공통 시각 기준은 [Design System](./design-system.md)을 따릅니다.

## 공통 원칙

- 화면은 현재 선택한 장부와 예산 기간을 항상 명확히 보여줍니다.
- 공동 장부의 개인정보는 V1 Scope의 공개 범위를 따릅니다.
- 금액은 색에만 의존하지 않고 라벨, 부호와 상태 문구를 함께 사용합니다.
- 좁은 화면에서 주요 행동과 금액이 잘리지 않아야 합니다.
- 로딩, 빈 상태, 오류, 긴 이름과 큰 금액을 기본 상태로 설계합니다.

## 최초 가입

- 목적: 카카오 로그인 사용자가 서비스 닉네임을 확정하고 기본 개인 장부로 진입합니다.
- 주요 행동: 닉네임 확정.
- 필수 정보: 카카오 닉네임 기본값, 수정 가능한 서비스 닉네임.
- 상태: 로그인 실패, 닉네임 검증 오류, 초대 링크 복귀.

## 장부 선택과 공동 장부 생성

- 목적: 기본 개인 장부와 공동 장부를 전환하거나 새 공동 장부를 만듭니다.
- 주요 행동: 장부 선택 또는 공동 장부 생성.
- 필수 정보: 장부 이름, 장부 유형, 현재 선택 상태.
- 공동 장부 생성 필수값: 이름, 전체 예산, 예산 기간 시작일.
- 상태: 공동 장부 없음, 접근 불가, 생성 실패.

## 홈 대시보드

- 목적: 현재 예산 기간에 사용할 수 있는 공동 금액과 본인 금액을 빠르게 확인합니다.
- 주요 행동: 거래 기록 또는 예산 상세 진입.
- 정보 순서:
  1. 현재 장부와 예산 기간
  2. 공동 예산 사용 가능액
  3. 본인 예산 사용 가능액
  4. 주간 예산 가이드
  5. 기간 수입 합계
  6. 공동 거래와 본인 거래로 구성된 최근 거래
- 예산 카드: 사용 가능액을 가장 크게, 현재 잔액·사용액·전체 예산·사용률을 함께 표시합니다.
- 초과 상태: 0원으로 자르지 않고 음수 금액과 초과 문구를 표시합니다.
- 상대방 개인 예산과 거래는 홈에 표시하지 않습니다.
- 전역 `+`: 빠른 기록, 영수증 사진, 카드사 앱 캡처를 선택합니다.
- 상태: 예산 미설정, 상대방 미참여, 거래 없음, 집계 실패.

## 거래 목록

- 목적: 현재 장부의 거래를 날짜순으로 탐색합니다.
- 주요 행동: 검색·필터 또는 거래 상세 진입.
- 검색: 사용처와 메모.
- 필터: 거래 유형, 대분류·소분류, 공동·본인 예산, 일반·고정비·할부, 공유 여부.
- 달력 전환은 제공하지 않습니다.
- 상대방 개인 거래는 공유된 거래만 표시합니다.
- 상태: 결과 없음, 미분류 거래 존재, 불러오기 실패.

## 빠른 기록

- 목적: 최소 입력으로 거래를 저장합니다.
- 주요 행동: 저장 또는 저장 후 계속 입력.
- 필수값: 금액, 사용처, 카테고리.
- 기본값: 오늘 날짜, 사용자와 장부별 마지막 차감 예산.
- 선택값: 시간, 메모, 결제수단, 개인 거래 공유.
- 카드 지출: 일시불 또는 할부와 할부 상세.
- 계좌이체: 내 계좌 간 이체, 송금, 입금 중 하나를 선택합니다.
- 상태: 필수값 누락, 상대방 예산 선택 불가, 저장 실패.

## 이미지 가져오기 검토

- 목적: 여러 이미지에서 인식한 거래를 한 번에 검토하고 저장합니다.
- 주요 행동: 선택 후보 일괄 저장.
- 필수 정보: 날짜, 금액, 사용처, 카테고리, 차감 예산, 중복 상태.
- 정상 후보는 기본 선택하고 중복 의심 후보는 선택 해제와 빨간색 테두리로 구분합니다.
- 차감 예산과 카테고리는 여러 후보를 선택해 일괄 변경할 수 있습니다.
- 날짜와 사용처는 후보별로 수정합니다.
- 신뢰할 수 없는 후보는 숨기고 제외 건수만 표시합니다.
- 상태: 인식 후보 없음, 일부 제외, 중복 후보, 저장 실패.

## 거래 상세

- 목적: 거래와 공개 상태를 확인하고 권한에 따라 변경합니다.
- 주요 행동: 수정, 공유 변경 또는 삭제.
- 필수 정보: 유형, 금액, 날짜·시간, 사용처, 카테고리 스냅샷, 예산, 결제수단, 메모.
- 할부 정보: 전체 금액, 월 이자, 현재 회차와 전체 회차.
- 공동 거래 변경 정보: 마지막 변경 사용자와 시각.
- 상대방 개인 거래: 공유된 항목만 읽기 전용으로 표시합니다.
- 상태: 접근 불가, 삭제된 거래, 수정 권한 없음.

## 예산 설정

- 목적: 현재 또는 다음 예산 기간의 전체·멤버별·공동·대분류 예산을 설정합니다.
- 주요 행동: 예산 저장 또는 현재 기간 설정 복사.
- 필수 정보: 예산 기간, 전체 예산, 멤버별 할당, 공동 예산, 예비비, 미배분 금액.
- 공동 대분류 예산은 두 사용자가, 본인 대분류 예산은 본인만 조회·변경합니다.
- 배분 합계가 상위 예산을 초과하면 상위 예산 증액 여부를 확인합니다.
- 현재 기간 변경 시 이번 기간만 또는 이후 기본값까지 적용할지 선택합니다.
- 상태: 상대방 미참여, 미배분 금액, 초과 배분, 저장 실패.

## 지난 기간 요약

- 목적: 종료된 기간의 결과를 확인합니다.
- 필수 정보: 공동·본인 예산의 사용·잔액·초과액, 대분류 지출, 미분류 건수, 이어지는 고정비·할부.
- 과거 거래를 변경하면 요약과 분석을 다시 계산합니다.
- 상대방 개인 예산의 세부 내역은 표시하지 않습니다.

## 분석

- 목적: 현재 장부의 대분류 소비와 기간 추세를 이해합니다.
- 주요 행동: 범위·기간 변경 또는 대분류 선택.
- 대표 지표: 총지출.
- 범위: 전체, 공동 예산, 내 예산.
- 정보: 대분류 원형 그래프, 금액·비율 목록, 일별·누적 흐름, 이전 기간 비교, 6·12개 기간 추세.
- 대분류 선택 시 해당 거래 목록을 표시합니다.
- 수입은 별도 영역에서 분석하고 예산 사용률에 합산하지 않습니다.
- 미분류 거래는 별도 대분류처럼 표시합니다.
- 상태: 분석 데이터 없음, 비교 기간 없음, 차트 로딩 실패.

## 카테고리 관리

- 목적: 고정 대분류의 표시 여부와 장부별 소분류를 관리합니다.
- 주요 행동: 소분류 생성·이름 변경·삭제.
- 대분류는 이름과 개수를 변경할 수 없고 장부별 숨김만 제공합니다.
- 소분류 이름 변경 시 이후 거래만 또는 과거 거래 스냅샷까지 적용할지 선택합니다.
- 삭제한 소분류는 과거 거래에 남지만 새 거래와 추천에서는 제외합니다.
- 미분류 거래 목록과 일괄 분류로 이동할 수 있습니다.
- 상태: 이름 중복, 숨겨진 대분류, 저장 실패.

## 반복 거래·고정비·할부

- 목적: 앞으로 자동 등록될 지출과 예정액을 관리합니다.
- 주요 행동: 생성, 수정, 일시정지, 재개 또는 삭제.
- 반복 주기: 매주, 매월, 매년.
- 고정비: 반복 지출에서 사용자가 선택합니다.
- 할부: 전체 금액, 개월 수, 월 이자와 회차를 표시합니다.
- 수정 시 이번 거래와 이후 예정 거래 적용 여부를 확인합니다.
- 상태: 자동 등록 일시정지, 발생일 오류, 해당 월 말일 보정, 저장 실패.

## 초대 링크

- 목적: 초대받은 사용자가 공동 장부를 확인하고 참여합니다.
- 주요 행동: 수락 또는 거절.
- 필수 정보: 장부 이름, 초대한 사용자, 남은 유효시간.
- 로그인하지 않은 사용자는 로그인 후 같은 화면으로 돌아옵니다.
- 상태: 만료, 새 링크로 교체, 이미 수락, 정원 초과, 동일 사용자.

## 공동 장부 설정

- 목적: 장부 이름, 초대, 멤버, 소유권과 개인 거래 공유를 관리합니다.
- 주요 행동: 링크 생성, 멤버 내보내기, 소유권 이전 또는 공유 기본값 변경.
- 장부 보관과 영구 삭제는 제공하지 않습니다.
- 탈퇴 또는 내보내기 전에 권한과 데이터 변화를 명확히 확인합니다.
- 상태: 상대방 미참여, 활성 링크, 읽기 전용 참여 기록.

## 알림함

- 목적: 예산, 다음 기간 설정과 장부 상태 변화를 확인합니다.
- 주요 행동: 관련 화면 이동, 개별 읽음 또는 모두 읽음.
- 필수 정보: 알림 유형, 장부, 발생 시각, 읽음 상태.
- 사용자가 직접 삭제할 수 없고 새 예산 기간이 시작되면 이전 기간 알림을 제거합니다.
- 상태: 알림 없음, 읽지 않은 알림 없음, 불러오기 실패.
