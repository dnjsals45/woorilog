# Product Brief

## Product

우리로그는 커플과 부부가 공동 생활비와 각자에게 할당된 예산을 함께 운영하는 가계부입니다.

개인 장부와 두 사람이 함께 쓰는 공동 장부를 같은 서비스에서 제공하며, 기록 부담을 줄이고 현재 예산 상태를 빠르게 이해하는 데 집중합니다.

## Problem

- 공동 지출, 남은 공동 예산과 본인 할당 예산을 한눈에 파악하기 어렵습니다.
- 공동 목적의 지출과 실제 결제자가 섞이면 예산이 어디에서 사용됐는지 이해하기 어렵습니다.
- 거래를 하나씩 수기로 입력해야 하면 기록이 밀립니다.
- 공동 장부 생성, 상대방 초대, 예산 배분과 사용 현황이 하나의 흐름으로 연결되지 않습니다.

## Target Users

- 공동 생활비와 예산 기간별 계획을 함께 관리하려는 커플과 부부
- 공동 예산과 별도로 각자의 할당 예산을 운영하는 커플과 부부
- 공동 장부와 함께 본인의 개인 장부도 관리하려는 사용자

현재 목표 사용자는 커플과 부부입니다. 가족, 룸메이트, 여행, 모임과 프로젝트 비용 관리는 현재 목표에 포함하지 않습니다.

## Core Experience

사용자는 우리로그에서 다음을 할 수 있어야 합니다.

1. 개인 장부에서 바로 기록을 시작하고, 필요하면 두 사람이 쓰는 공동 장부를 만듭니다.
2. 한 기간의 전체 예산을 본인·상대방·공동 예산으로 배분하고 남은 금액은 예비비로 관리합니다.
3. 지출·수입·계좌이체를 수기로 기록하거나 영수증·카드사 앱 캡처에서 여러 거래를 빠르게 가져옵니다.
4. 공동 장부 대시보드에서 공동 예산과 본인 할당 예산의 사용 현황을 우선 확인합니다.
5. 예산 초과 알림과 주간 권장액으로 남은 기간의 소비 속도를 조절합니다.

## Feature Areas

- [시작과 장부 관리](./v1-scope.md#시작과-장부-관리): 최초 가입, 개인 장부, 공동 장부 생성, 링크 초대와 역할
- [예산 설정](./v1-scope.md#예산-설정): 예산 기간, 멤버별·공동 배분, 예비비와 차감 규칙
- [거래 입력](./v1-scope.md#거래-입력): 빠른 기록, 이미지 일괄 가져오기, 수정·공유, 반복 거래와 고정비
- [대시보드와 상세 조회](./v1-scope.md#대시보드와-상세-조회): 사용 가능액, 최근 거래, 상세 공개 범위와 거래 검색
- [카테고리와 분석](./v1-scope.md#카테고리와-분석): 장부별 카테고리, 거래 스냅샷, 카테고리 예산과 소비 추세
- [예산 알림](./v1-scope.md#예산-알림): 사용률 알림, 변경 알림과 주간 예산 가이드

세부 기능 규칙의 원본은 [V1 Scope](./v1-scope.md)에서 관리합니다.

## Product Principles

- 기록은 빠르게, 검토는 한눈에 보이게 만듭니다.
- 결제자보다 돈을 사용한 목적을 기준으로 예산을 차감합니다.
- 공동 예산은 두 사람에게 투명하게, 개인 할당 예산의 일상 정보는 본인 중심으로 보여줍니다.
- 자동 인식 결과는 사용자가 검토하고 보정할 수 있어야 합니다.
- 별도 튜토리얼보다 현재 상태에 맞는 다음 행동을 안내합니다.
- 현재 범위에 없는 기능은 확정된 정책처럼 문서화하지 않습니다.

## Success Criteria

- 신규 사용자가 기본 개인 장부에서 바로 거래를 기록할 수 있습니다.
- 사용자가 공동 장부를 만들고 링크로 상대방을 초대해 첫 예산 배분을 완료할 수 있습니다.
- 사용자가 공동 예산과 본인 할당 예산의 사용액·잔액을 대시보드에서 확인할 수 있습니다.
- 사용자가 하루치 여러 거래를 한 번의 가져오기와 검토 흐름으로 저장할 수 있습니다.
- 공동 예산 알림은 두 사용자에게, 개인 예산 알림은 해당 사용자에게만 전달됩니다.
- 사용자가 주간 사용 흐름과 다음 주 권장액을 확인할 수 있습니다.
- 주요 기능은 API 계약, 테스트와 문서로 함께 유지됩니다.
