# User Flows

이 문서는 [V1 Scope](./v1-scope.md)에 확정된 정책을 사용자가 실제로 수행하는 순서로 설명합니다.
세부 금액 계산, 권한과 공개 범위는 V1 Scope를 원본으로 사용합니다.

## 1. 최초 로그인

1. 사용자가 카카오로 로그인합니다.
2. 최초 가입이면 카카오 닉네임을 기본값으로 제시하고 서비스 닉네임을 확정하게 합니다.
3. 서버가 항상 표시되는 기본 개인 장부를 자동 생성합니다.
4. 별도 튜토리얼 없이 개인 장부의 빈 상태에서 첫 거래 기록 또는 예산 설정을 안내합니다.
5. 일반 로그인은 기본 개인 장부로, 초대 링크에서 시작한 로그인은 원래 초대 확인 화면으로 이동합니다.

## 2. 장부 전환과 공동 장부 생성

1. 사용자가 장부 선택기를 엽니다.
2. 기본 개인 장부와 사용자가 만들거나 참여한 공동 장부가 함께 표시됩니다.
3. 사용자가 장부를 선택하면 대시보드, 거래, 예산과 분석이 해당 장부 기준으로 갱신됩니다.
4. 공동 장부를 만들 때 장부 이름, 전체 예산과 예산 기간 시작일을 설정합니다.
5. 생성한 사용자는 `OWNER`가 되고, 상대방이 참여하기 전에는 멤버별·공동 예산을 배분하지 않습니다.
6. 생성 완료 후 링크 초대로 이어집니다.

## 3. 링크 초대

1. `OWNER`가 30분 동안 유효한 초대 링크를 생성해 상대방에게 공유합니다.
2. 새 링크를 생성하면 기존 활성 링크는 즉시 무효화됩니다.
3. 로그인하지 않은 사용자가 링크를 열면 카카오 로그인과 닉네임 확정 후 같은 초대 확인 화면으로 돌아옵니다.
4. 초대받은 사용자는 장부 이름과 초대한 사용자를 확인하고 수락 또는 거절합니다.
5. 수락하면 링크가 즉시 만료되고 사용자는 `MEMBER`로 참여합니다.
6. 수락한 공동 장부를 현재 장부로 선택하고 대시보드로 이동합니다.
7. 두 사용자가 참여했지만 배분이 없다면 예산 설정을 첫 행동으로 안내합니다.

## 4. 첫 예산 배분

1. 두 사용자가 현재 예산 기간의 전체 예산을 확인합니다.
2. 멤버 A 할당, 멤버 B 할당과 공동 예산을 입력합니다.
3. 배분 합계가 전체 예산보다 작으면 차액을 예비비로 자동 계산합니다.
4. 배분 합계가 전체 예산을 초과하면 전체 예산 증액 여부를 확인합니다.
5. 사용자가 증액을 거절하면 저장하지 않고 배분 금액을 다시 조정합니다.
6. 각 사용자는 본인 할당 예산의 대분류별 예산을 비공개로 설정할 수 있습니다.
7. 두 사용자는 공동 예산의 대분류별 예산을 함께 설정할 수 있습니다.
8. 설정을 저장하면 공동 장부 대시보드가 공동 예산과 로그인한 사용자의 예산을 표시합니다.

## 5. 다음 예산 기간

1. 사용자는 다음 예산 기간의 전체·멤버별·공동·대분류 예산을 미리 설정할 수 있습니다.
2. 시작 3일 전까지 설정하지 않으면 설정 권한이 있는 사용자에게 앱 내부 안내 알림을 보냅니다.
3. 알림에서 현재 기간 설정을 복사하거나 다음 기간 예산을 직접 입력합니다.
4. 아무도 설정하지 않으면 새 기간 시작 시 현재 기간의 설정을 자동 복사합니다.
5. 이전 기간의 실제 잔액과 초과액은 이월하지 않고 이전 기간 결과로만 보존합니다.
6. 고정비, 할부와 반복 거래는 다음 기간에도 이어집니다.

## 6. 빠른 거래 기록

1. 사용자가 작은 `+` 버튼을 누르고 빠른 기록을 선택합니다.
2. 금액 키패드가 바로 열립니다.
3. 사용자가 지출, 수입 또는 계좌이체를 선택합니다.
4. 금액, 사용처와 카테고리를 입력합니다. 날짜는 오늘, 차감 예산은 사용자와 장부의 마지막 선택값을 기본으로 사용합니다.
5. 시간, 메모와 결제수단은 필요할 때 입력합니다.
6. 카드 지출이면 일시불 또는 할부를 선택합니다.
7. 공동 장부 지출은 본인 할당 예산 또는 공동 예산만 선택할 수 있습니다.
8. 저장하면 대시보드와 분석이 갱신됩니다.
9. `저장 후 계속 입력`을 선택하면 같은 화면에서 다음 거래를 이어서 기록합니다.

## 7. 계좌이체 기록

1. 사용자가 거래 유형으로 계좌이체를 선택합니다.
2. `내 계좌 간 이체`, `다른 곳으로 송금`, `외부에서 입금` 중 하나를 선택합니다.
3. 카테고리와 상대 계좌 또는 상대방을 사용처에 입력합니다.
4. 내 계좌 간 이체는 예산과 수입·지출 통계에서 제외합니다.
5. 다른 곳으로 송금은 지출로 처리하고 선택 예산에서 차감합니다.
6. 외부에서 입금은 수입으로 집계하지만 설정된 예산은 늘리지 않습니다.

## 8. 이미지 일괄 가져오기

1. 사용자가 `+` 버튼에서 영수증 사진 또는 카드사 앱 캡처를 선택합니다.
2. 여러 이미지를 선택하면 서버가 인식한 정상 후보를 하나의 검토 목록으로 합칩니다.
3. 필수 정보를 신뢰할 수 없는 결과는 후보로 보여주지 않고 제외 건수만 안내합니다.
4. 정상 후보는 기본 선택하고 중복 의심 후보는 선택 해제한 뒤 빨간색 테두리로 표시합니다.
5. 공동 장부 후보는 업로드한 사용자의 할당 예산을 기본으로 선택합니다.
6. 사용자는 여러 후보의 차감 예산 또는 카테고리를 한 번에 변경할 수 있습니다.
7. 사용자는 후보별 날짜와 사용처를 검토하고 필요한 항목만 수정합니다.
8. 카테고리를 확정할 수 없는 후보는 `미분류`로 저장할 수 있습니다.
9. 검토를 마친 후보만 한 번에 저장합니다.

## 9. 거래 수정·공유·삭제

1. 사용자가 날짜순 거래 목록에서 거래를 선택합니다.
2. 본인 할당 예산 거래는 기록한 본인만 수정·삭제할 수 있습니다.
3. 공동 예산 거래는 두 사용자 모두 수정·삭제할 수 있고 변경한 사용자와 시각을 남깁니다.
4. 본인 개인 거래는 기본 비공개이며 거래별로 상대방 공유 여부를 변경할 수 있습니다.
5. 전체 공유를 켜면 기존 개인 거래와 이후 새 거래를 공유하고, 특정 거래는 다시 비공개로 바꿀 수 있습니다.
6. 거래를 삭제하면 반영된 예산을 되돌리고 삭제 이력은 남기지 않습니다.
7. 지난 예산 기간의 거래도 수정할 수 있지만 새 예산 알림은 생성하지 않습니다.

## 10. 할부·반복 거래·고정비

1. 할부 거래는 전체 결제 금액, 개월 수와 월 이자 금액을 입력합니다.
2. 서버가 회차별 원금과 월 이자를 계산해 각 결제월에 자동 등록합니다.
3. 거래 상세에는 전체 금액과 현재 회차를 표시합니다.
4. 반복 지출은 매주, 매월 또는 매년 주기와 발생일을 설정합니다.
5. 반복일이 해당 월에 없으면 그 달의 말일에 자동 등록합니다.
6. 사용자는 반복 지출을 고정비로 표시해 별도로 모아볼 수 있습니다.
7. 반복 거래를 수정할 때 이번 거래와 이후 예정 거래의 변경 여부를 확인합니다.
8. 중단하거나 삭제해도 이미 생성된 과거 거래는 유지합니다.

## 11. 대시보드와 상세 조회

1. 대시보드는 장부에 설정한 현재 예산 기간을 기준으로 집계합니다.
2. 공동 예산의 사용 가능액을 가장 먼저, 본인 할당 예산을 그다음에 표시합니다.
3. 사용 가능액은 현재 잔액에서 남은 고정비와 할부 예정액을 뺀 금액입니다.
4. 수입은 예산과 분리된 기간 합계로 표시합니다.
5. 최근 거래에는 공동 예산 거래와 본인 개인 거래만 시간순으로 표시합니다.
6. 주간 예산 가이드는 다음 가이드가 생성될 때까지 대시보드에 유지합니다.
7. 예산 카드를 선택하면 금액, 대분류별 사용액, 날짜별 흐름, 거래 목록과 예정 지출을 상세 조회합니다.
8. 이전 예산 기간으로 이동하면 같은 구조의 과거 대시보드를 조회합니다.

## 12. 카테고리 관리와 분석

1. 새 장부에는 V1 Scope에 정의된 고정 대분류와 기본 소분류를 생성합니다.
2. 사용자는 장부별 소분류를 생성·이름 변경·삭제하고 사용하지 않는 대분류를 숨길 수 있습니다.
3. 거래 저장 시 대분류와 소분류를 스냅샷으로 보존합니다.
4. 소분류를 삭제해도 과거 거래의 표시와 대분류 분석은 유지됩니다.
5. 미분류 거래는 별도 목록에서 여러 건을 선택해 한 번에 분류할 수 있습니다.
6. 분석은 현재 장부의 공동 예산 거래와 로그인한 사용자의 개인 거래만 포함합니다.
7. 사용자는 전체, 공동 예산과 내 예산 범위를 전환합니다.
8. 대분류 원형 그래프, 일별·누적 흐름, 이전 기간 비교와 6·12개 기간 추세를 확인합니다.
9. 대분류를 선택하면 해당 거래 목록을 확인합니다.

## 13. 예산 알림과 주간 가이드

1. 공동 예산 또는 대분류 예산이 80%와 100% 기준을 넘으면 공개 범위에 맞는 사용자에게 앱 내부 알림을 보냅니다.
2. 기준 이상인 동안에는 반복하지 않고, 기준 아래로 내려갔다 다시 넘으면 같은 기간에도 다시 알립니다.
3. 고정비·할부 자동 등록과 현재 기간의 뒤늦은 거래 등록에도 같은 규칙을 적용합니다.
4. 사용자는 80% 알림과 일요일 주간 가이드를 끌 수 있습니다.
5. 100%·초과 알림과 공동 예산 변경 알림은 끌 수 없습니다.
6. 매주 일요일 오후 9시에 공동 예산과 본인 예산의 다음 주 권장액을 생성합니다.
7. 사용자는 알림을 개별 또는 모두 읽음 처리할 수 있습니다.
8. 장부의 다음 예산 기간이 시작되면 이전 기간 알림을 자동으로 제거합니다.

## 14. 탈퇴·내보내기와 재참여

1. `MEMBER`는 강한 확인 절차를 거쳐 공동 장부에서 탈퇴할 수 있습니다.
2. `OWNER`가 멤버를 내보내면 해당 사용자에게 앱 내부 알림을 보냅니다.
3. `OWNER`가 떠나려면 먼저 기존 `MEMBER`에게 소유권을 이전합니다.
4. 탈퇴 또는 내보내기 시 공동 장부의 자동 거래를 모두 일시정지하고 남은 사용자에게 알립니다.
5. 탈퇴한 사용자는 참여했던 기간의 본인 개인 거래와 공동 거래를 읽기 전용으로 조회합니다.
6. 남은 사용자는 공동 거래와 탈퇴 전에 공유된 상대방 개인 거래만 조회합니다.
7. 동일한 상대방은 새 링크로 다시 참여할 수 있지만 전혀 다른 사용자는 기존 장부에 참여할 수 없습니다.
8. 공동 장부는 보관하거나 영구 삭제하지 않습니다.
